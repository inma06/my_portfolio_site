# 운세저장소 백엔드/풀스택 개발 — 2026.02 ~ 2026.05

## 프로젝트 개요
Node.js·Express 기반의 사주 리포트 결제·발급 서비스 "운세저장소"의 백엔드/풀스택 개발을 단독으로 담당했습니다. 토스페이먼츠 결제 연동, GPT 기반 리포트 생성 파이프라인, 관리자 백오피스, 사주 계산 엔진을 모두 다루며 약 3.5개월간 **170여 건의 커밋**을 만들었습니다.

## 주요 성과

- **토스페이먼츠 v2 SDK 전환 및 결제 안정화** — v1에서 v2 위젯으로 전면 업그레이드하고, `ready` 이벤트 기반 렌더링 감지, 초기화 가드, 중복 생성 방지 가드를 추가해 결제 페이지의 잠재 결함을 제거했습니다. 결제→리포트 발급 사이 타이밍 이슈로 발생하던 중복 주문/티켓 미발급 버그를 해결하고, 불필요한 재시도 로직을 제거해 결제 플로우를 단순화했습니다.

- **신규 상품 2종 출시** — **신년사주**와 **재회사주** 상품을 랜딩 페이지·미리보기·결제·리포트 생성까지 풀스택으로 신규 구축했습니다. GPT 미리보기 + 블러 처리 + 결제 유도 패턴으로 전환율 향상을 노렸고, 번들 상품(연애+29금, 재회+29금)과 가격 분기·테스트폰 분기 로직을 도입했습니다.

- **관리자 백오피스 구축** — bcrypt 기반 인증과 **슈퍼어드민 권한 분리(결제내역 접근 제한)**, 매출 API, 리포트 내역 조회·재발급(검색·페이징·GPT 진행률 표시), 미리보기 통계(방문/전환율) 기능을 만들었습니다. **GPT_LOG 테이블**로 리포트 파트별 호출을 로깅하고, **SMS_HISTORY에 msg_id**를 추가해 Aligo 발송 건을 1:1 추적할 수 있도록 했습니다.

- **사주 계산 엔진 정밀도 개선** — 전통 만세력 기준으로 절기·진태양시·서머타임·지역시 보정을 도입했고, 동지 기간 년주 오류, 야자시(24시) 시주 오류, 지지 申/천간 辛 혼동, 여자 사주가 남자 대운으로 계산되던 성별 문자열 불일치, 대운수 절(節) 기준 계산 등 핵심 버그들을 차례로 잡았습니다.

- **NestJS 마이그레이션 및 리팩토링** — 레거시 Express 코드 위에 NestJS 1~5단계 마이그레이션을 진행하면서 Repository 패턴, 통합 에러 처리, 설정 모듈, 데드코드 제거, Jest/Playwright 테스트 인프라를 함께 도입했습니다.

- **모바일 UX 개선** — iOS Safari·Android Chrome의 키보드 노출 시 발생하던 흰 여백·레이아웃 점프·버튼 이중 점프 문제를 폴링 기반 키보드 감지로 해결하고, `100dvh` + viewport `interactive-widget` 조합을 적용했습니다.

## 사용 기술
Node.js, Express, NestJS, Sequelize, MySQL, EJS, Tailwind, PM2, Toss Payments v2, Aligo SMS, OpenAI GPT, Jest, Playwright
