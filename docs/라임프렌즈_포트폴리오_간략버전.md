# 라임프렌즈 (Just Thank You) — 2022.05 ~ 2023.01

## 프로젝트 개요
일상에서 누군가에게 전하고 싶은 감사를 카드와 짧은 글로 표현하는 감성 SNS 앱. Flutter 기반으로 iOS · Android 동시 운영했고, 단순 SNS 도메인을 넘어 **"감사 카드 선물하기" 결제 흐름**까지 함께 다뤘습니다.

## 주요 성과

- **CI/CD 정비로 빌드/QA 사이클 단축** — Flutter Flavor 로 dev / staging / prod 환경을 분리하고, Fastlane 으로 코드 사이닝·빌드 번호 증가·스토어 업로드까지 한 명령으로 처리되도록 파이프라인을 자동화했습니다. 매 QA 전달마다 손으로 잡던 단계가 사라지면서, 기획·디자인 피드백을 받은 당일 안에 검증 빌드를 올리는 사이클이 가능해졌습니다.

- **장기 운영을 견디는 아키텍처 정착 (BLoC + DDD + Layered Architecture)** — Domain / Application / Infrastructure / Presentation 4계층으로 폴더 구조를 잡고, 도메인 레이어가 외부 의존성에 묶이지 않도록 Repository 인터페이스 기반 의존성 역전을 유지했습니다. 신규 기능 추가 시 영향 범위가 좁아지고, 추후 백엔드 전환 같은 큰 변경에서도 Infrastructure 계층만 교체할 수 있는 기반이 되었습니다.

- **백엔드 마이그레이션 대응 (Firebase Firestore → AWS Lambda + PostgreSQL)** — 기존 Firestore SDK 직접 호출 / snapshot listener 의존 코드를, REST 기반의 새 API 스펙·데이터 모델·갱신 흐름에 맞춰 클라이언트 측을 재구성했습니다. 추상화 레이어 덕분에 화면 단 변경을 최소화하면서 점진적으로 이관할 수 있었습니다.

- **스토어 심사 대응 — Google UGC 정책 반려** — 신고·차단·사후 모더레이션 흐름과 정책 문구를 보강해 재심사 통과를 확보했습니다.

- **아임포트 기반 "선물하기" 결제 흐름** — 카드 선물 결제·검증·실패 처리 플로우를 구현했습니다.

## 사용 기술
Flutter, Dart, BLoC, DDD, Layered Architecture, Firebase (Firestore · Auth · Crashlytics), AWS Lambda, PostgreSQL, Fastlane, Flavor, 아임포트(IAMPORT)
