# 운세저장소 백엔드/풀스택 개발 상세 회고 — 2026.02.02 ~ 2026.05.21

## 1. 프로젝트 개요
운세저장소는 사용자가 생년월일·태어난 시·성별을 입력하면 GPT 기반으로 개인화된 사주 리포트(센슈얼사주, 신년사주, 재회사주, 29금 등)를 발급하는 결제형 웹 서비스입니다. 약 3.5개월간 백엔드 핵심 도메인 전 영역을 단독으로 개발·운영했고, **약 170건의 커밋**을 통해 신규 상품 출시, 결제 인프라 전환, 관리자 백오피스 구축, 사주 엔진 정밀화, NestJS 점진 마이그레이션을 동시에 진행했습니다.

## 2. 결제 시스템 — 토스페이먼츠 v2 전환과 안정화

가장 큰 인프라 작업은 토스페이먼츠 결제 위젯의 **v1 → v2 SDK 업그레이드**였습니다. 단순 SDK 교체에 그치지 않고, 다음과 같은 신뢰성 문제를 차례로 해결했습니다.

- **렌더링 완료 감지** — 위젯 `ready` 이벤트를 명시적으로 구독해 렌더링이 끝나기 전 결제 요청이 발생하는 경합을 차단했습니다(`a4b2425`, `c2802ec`).
- **초기화 가드** — 중복 초기화로 인한 위젯 깨짐을 방지하는 가드를 추가했습니다(`73f1328`).
- **결제 플로우 중복 생성 방지** — 클라이언트 재시도와 서버 콜백이 겹치며 동일 주문에 대해 리포트가 두 번 생성되던 문제를, 주문번호(`shopOrderNo`) 기반의 멱등성 처리로 해결했습니다(`3849c89`, `7d62e20`).
- **불필요한 재시도 로직 제거** — 결제 페이지에 누적되어 있던 방어적 재시도들이 오히려 타이밍 이슈를 만들고 있어 전면 정리했습니다(`481396b`).
- **번들 티켓 처리** — 번들 상품의 티켓이 미발급되는 케이스를 신규 생성으로 보완하고, SMS에 티켓번호가 함께 발송되도록 했습니다(`a23ca89`, `07a31ff`).

별도로 **EasyPay 복구 → 토스 전환**을 단계적으로 진행하고, 점검 모드(`c8b820a`)와 테스트폰 결제 분기(`884d47a`, `df668fd`)도 함께 도입해 운영 안정성을 확보했습니다.

## 3. 신규 상품 2종 출시 — 신년사주 / 재회사주

기존 센슈얼사주(클래식) 한 종이던 라인업에 두 가지 상품을 풀스택으로 추가했습니다.

- **신년사주** — 상세 페이지, 미리보기(GPT 800자, 블러 처리 + 결제 유도), 결제 분기, 보고서 생성을 모두 신규 구축했습니다. 가격은 29,800원 → 35,900원, 번들은 49,800원 → 51,900원으로 조정해 단가를 끌어올렸습니다.
- **재회사주** — 인트로/입력/결과 UI 개선, 온도 표시, 재회+29금 번들, **재회 타이밍 가이드의 하드코딩 날짜를 발급일 기준 동적 산정으로 교체**해 "과거 시점을 제시하던" 치명적인 콘텐츠 버그를 해결했습니다(`fd560cd`, `01fdb72`).

추가로 클래식 리포트에서는 **남성/여성 프롬프트를 분리**하고 이미지 리소스를 성별 폴더로 재구성했으며, 도화살 개인화·BDSM/페티시 유형 사주 기반 선택 기준·TOP3 데이터 사전 10개 확장 등 콘텐츠 다양성을 끌어올렸습니다.

## 4. 관리자 백오피스 — TIGHT Admin

운영자가 직접 사용할 수 있는 관리자 페이지를 신규 구축한 것이 가장 어필 포인트입니다.

- **인증·권한** — bcrypt 기반 로그인, **슈퍼어드민 권한 도입과 결제내역 접근 제한**(`2d29a3e`)으로 권한 분리를 명확히 했습니다.
- **리포트 운영** — 리포트 내역 조회(검색·페이징), **재발급 기능**, **GPT 호출 진행률 표시**(`b2b98a7`), 500 에러 시 상세 원인 노출, 무한 로딩 수정, 발급 체감 속도 개선을 단계적으로 진행했습니다.
- **GPT 로깅** — `GPT_LOG` 테이블을 신설해 리포트 **파트별 GPT 호출**을 모두 적재하고, `shopOrderNo`를 키로 결제↔리포트 추적을 일원화했습니다(`8e22709`, `943342e`).
- **SMS 추적** — `SMS_HISTORY`에 Aligo `msg_id` 컬럼을 추가해 발송 건별 식별이 가능하도록 했습니다(`52e49a3`).
- **외부 API** — 외부 API 규약 정의, API_KEYS 테이블 마이그레이션, 매출 API, 미리보기 API와 통계(방문율·전환율) API를 정비했습니다.
