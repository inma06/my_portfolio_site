# 밀크코퍼레이션 유아동복 앱 — 2021.07 ~ 2022.04 (10개월)

## 프로젝트 개요
유아동복 쇼핑몰 모바일 앱의 **프론트엔드 전반을 단독으로 담당**했습니다. Flutter 기반으로 iOS · Android 동시 운영했고, **초기 셋업부터 1.3.0 정식 출시까지** 약 10개월간 책임지고 사이클을 굴렸습니다.

## 주요 성과

- **GetX 기반 상태관리 + 중복 라우팅 문제 정리** — 초기 단독 개발 환경에 부트스트랩 비용이 낮은 GetX 를 채택해 라우팅 / 상태 / 의존성 주입을 일관성 있게 사용했습니다. 사용자의 빠른 탭이나 푸시 / 딥링크 진입 시 같은 화면이 스택에 여러 번 쌓이던 문제를 라우팅 가드와 "현재 라우트와 같으면 push 무시" 규칙으로 통일해, 백 버튼 동작이 뒤틀리지 않도록 정착시켰습니다.

- **Firebase 통합으로 운영 안정화** — Auth · FCM · Crashlytics 를 한 번에 통합. 크래시 추적 → 핫픽스 사이클을 짧게 가져갈 수 있는 운영 기반을 만들었습니다.

- **결제·애널리틱스 SDK 연동** — 아임포트 결제 SDK 로 결제 흐름과 서버 검증을 묶었고, **에어브릿지(Airbridge AB108)** 어트리뷰션 SDK 로 신규 설치 / 회원가입 / 결제 등 핵심 전환 이벤트를 광고 채널별로 추적할 수 있게 했습니다.

- **권장 / 강제 업데이트 게이트** — 서버 응답 기반으로 권장(스킵 가능) / 강제(스킵 불가) 업데이트 모달을 제공. **운영팀이 서버 설정만으로 즉시 강제 업데이트를 켤 수 있게** 해, 결제·인증 이슈가 있는 구버전 단말에 사용자가 묶이지 않도록 차단했습니다.

- **스토어 심사 반려 대응 노하우 확보** — 출시·업데이트 과정에서 받은 반려 사유를 유형별로 정리해 재제출 흐름을 정착시켰고, 이후 다른 프로젝트의 심사 대응에서도 같은 패턴으로 활용할 수 있게 되었습니다.

## 사용 기술
Flutter, Dart, GetX, Firebase (Auth · FCM · Crashlytics), 아임포트(IAMPORT), 에어브릿지(Airbridge AB108)
